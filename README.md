## 1. 基于 LangGraph 的工业基座模型微调 Agent 系统
> **关键词：** LangGraph + RAG + SQLite | LoRA微调 | Agent 搭建

**项目背景：** 针对工业模型训练中算法选型依赖人工、流程割裂与状态难追踪等问题，开发面向本地微调的对话式 Agent 系统，打通意图解析、计划生成、任务执行、结果展示与计划迭代闭环。
**核心亮点：**
* **任务编排与意图路由（LangGraph+DeepSeek）**：基于 LangGraph 构建对话式任务编排内核，将自然语言需求映射为可控的图节点流转，覆盖通用问答、知识检索、计划生成/展示/修改/确认/取消、训练进度查询/结果查询/任务总结等命令类型；设计“控制指令优先、任务意图次之、知识问答补充”的分层路由策略，区分即时问答、任务型请求与流程控制指令，将 LLM 语义理解与规则化状态解耦，避免长流程任务被上下文漂移干扰，支撑数据分析、模型训练与结果总结三类核心任务的稳定流转。
* **记忆检索与知识增强（SQLite+RAG）**：以 SQLite 作为本地任务状态与结果真相源，持久化会话、计划、运行、结果，以支撑待确认计划、当前运行任务、历史计划与最近结果等关键状态恢复，使用户能够在多轮对话中修改计划、查询进度或追溯结果，避免长时任务完全依赖内存上下文；结合 Pydantic 数据契约统一约束数据集、任务计划、运行状态与结果记录等核心对象，接入本地 RAG 知识库沉淀 LoRA微调方法与工业具体任务知识，为数据画像、场景识别、策略推荐和计划生成提供可追溯依据。
* **工具执行与反馈闭环（Python工具链）**：将 LangGraph 节点收敛为轻量编排层，由服务层统筹数据分析、计划生成、训练执行、结果查询、报告生成与错误处理等业务流程，降低编排逻辑、状态管理与工具实现之间的耦合；封装数据画像、数据注册、模型训练、模型评测与可视化看板等工具组件，并通过 Worker 子进程执行长时任务，持续向SQLite回写任务进度、阶段结果、异常原因与诊断建议，使前端能够实时展示运行状态并支持失败追踪，形成“计划—确认—执行—反馈—复盘”的自动化闭环。

## 2. 基于视觉基座模型微调的复杂时变工况缺陷分类系统
> **关键词：** 低秩自适应 (LoRA) | ONNX 静态计算图

**项目背景：** 针对工业缺陷分类场景中训练样本稀缺、多维时变工况（噪声、模糊、光照畸变交织）及边缘部署困难等痛点，提出重参数稳秩RepRsLoRA机制扩充特征空间，并基于重参数化与 ONNX 实现无损脱机部署。
**核心亮点：**
* **双轨抗噪优化（结构扩充 & 方差稳定）：** 针对传统 LoRA 在复杂扰动下表征容量不足、高秩训练时信号衰减等问题，提出并行双旁路架构，在Attention层的QV线性层引入双低秩旁路以扩充训练期特征表达空间，配合修正缩放因子稳定特征方差以产生平滑正则化效应，增强模型在噪声、模糊、光照畸变交织场景下的稳定性。在小样本+混合干扰下，Rank=64时性能超越开销更大的Adapter等算法，Rank=256 时准确率达 84.67%，较传统 LoRA 绝对提升 16.67%。
* **极简离线部署（重参数化 & ONNX）：** 面向厂区终端算力有限问题，设计训练期扩容——推理期折叠的重参数化部署方案，双旁路增量矩阵无损合并至主干网络权重，使推理阶段无需额外加载 LoRA 分支，实现参数结构回收与推理图简化，实现推理端“0参数膨胀与0延迟增长”；针对网络环境受限和依赖难维护等部署约束，将计算图静态化编译为 ONNX 格式彻底剥离 Python 依赖，以极小体积在老旧厂区终端上实现跨平台跨 CPU/GPU 的低资源离线推理。

## 3. 基于扩散生成模型的医疗重症辅助诊断桌面系统
> **关键词：** 扩散生成模型 (DDPM) | Tauri+Vue3 原生调用 | ONNX 毫秒级极简推理

**项目背景：** 面向安医大一附院真实临床 ARDS 早期预警，解决医疗数据极度稀缺、类别严重不平衡及老旧设备无网/无算力的痛点。
**核心亮点：**
* **数据清洗处理与临床特征工程：** 围绕 28 项生命体征与生化指标构建可复现的数据处理管线，完成异常值逻辑校验、缺失值补齐与标准化处理，降低真实临床数据中噪声对模型训练的干扰；进一步构造 NLR、PLR、MAP 等临床衍生特征，并基于相关系数阈值剔除冗余维度，最终形成桌面端可复现的 30 维结构化输入，为后续生成增强、分类训练和 ONNX 推理提供统一特征空间。
* **掩码扩散生成与阈值动态寻优：** 提出特征掩码扩散模型FM-DDPM，训练时随机掩码特征维度并引入辅助自监督重建损失以学习特征间内在关联，约束生成空间以扩充非平衡训练数据集；结合验证集F1分数最大化阈值寻优，在12种分类模型上评估，相较于SMOTE算法F1与ACC提升18.9%与3.8%，相较于DDPM算法提升3.3%与0.6%，最优分类器F1与ACC为80.1%与94.9%。

* **离线推理管线与桌面终端交付：** 面向医院内网隔离、终端老旧等部署约束，将“缺失补齐—特征衍生—标准化—分类预测”的全链路推理管线统一固化为ONNX静态计算图；基于 Vue 3、Tauri 2开发离线桌面应用，设计 28 项生命体征与生化指标的一键录入、风险预测界面，实现本地毫秒级推理，交付适配医院老旧终端的仅20M免安装桌面软件。

## 4. 基于联邦学习的分布式多模态基座模型微调平台
> **关键词：** 云边协同架构 | 基座模型+LoRA | 全场景异构适配算法 | 全链路跨网段联调

**项目背景：** 依托工信部创新发展工程项目（1.75亿），解决工业边缘侧数据孤岛、多维异构（分布/算力/内存/带宽）及隐私安全痛点。
**核心亮点：**
* **平台通用设计与算法集成：** 主导设计底层网关与上层算法解耦的联邦学习架构，兼容主流联邦学习方案。针对数据稀缺导致的欠拟合问题，引入多模态基座模型提供先验知识；针对算力受限问题，采用INT8量化与LoRA微调降低部署门槛；针对带宽问题，支持分割联邦学习与梯度稀疏化压缩开销；针对投毒攻击风险，结合本地差分隐私与动态梯度裁剪构筑安全壁垒。
* **边端全场景异构感知适配：** 应对边端多维度异构挑战，构建全场景自适应优化机制。针对模态异构问题，内置图信息瓶颈GIB过滤结构冗余以对齐模态特征；针对数据异构问题，定制双轨近端正则与特征对抗机制以对齐用户特征；针对内存异构，设计秩异构LoRA蒸馏与免填充聚合以实现无损知识迁移；针对算力异构，引入异步聚合机制以提高训练效率。
* **跨网段联调与原型机交付：** 负责平台从0到1的核心功能验证。引入虚拟覆盖网络穿透网络隔离；基于Docker实现云边容器化解耦交付；构建轻量级无状态gRPC通信网关，利用Redis+MinIO（Claim-Check模式）统筹全局调度并实现断点续传容灾机制；集成Prometheus/Grafana/Jaeger搭建全链路大屏追踪训练状态。
